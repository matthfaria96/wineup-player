- Criar scripts/verify-app.sh (`#!/bin/bash`, `set -euo pipefail`, executável; arg 1 = caminho do .app, default "build/Wineup Player.app"; sempre aspas duplas em caminhos, que têm espaços):
  1. `otool -l "$BIN" | grep -A2 LC_RPATH | grep -q "@executable_path/../Frameworks"` senão erro "rpath ausente".
  2. Para o binário E para cada binário em `"$APP"/Contents/Frameworks/*.framework/` (resolver via `Versions/Current/<Nome>` ou `<Nome>`), ler `otool -L`; para cada dependência `@rpath/X.framework/...`, exigir `"$APP/Contents/Frameworks/X.framework"`; senão erro listando quem referencia o quê.
  3. `codesign --verify --deep --strict "$APP"`.
  4. Copiar com `ditto` para `TMP="$(mktemp -d)"` em `"$TMP/Wineup Player.app"`; `trap 'pkill -f "$TMP/Wineup Player.app/Contents/MacOS/Wineup" || true; rm -rf "$TMP"' EXIT`.
  5. Teste de dyld direto: rodar `"$TMP/Wineup Player.app/Contents/MacOS/Wineup" >"$TMP/direct.log" 2>&1 &`, `sleep 3`; se o PID morreu e o log contém "Library not loaded" ou "dyld", erro "dyld não resolveu frameworks"; senão `kill` o PID.
  6. `open -n "$TMP/Wineup Player.app"`, `sleep 3`, `pgrep -f "$TMP/Wineup Player.app/Contents/MacOS/Wineup" >/dev/null` (padrão entre aspas) senão erro "app não abriu fora de build/".
  7. Imprimir "Empacotamento OK". Mensagens pt-BR; código 1 em qualquer falha.

1. `TMP="$(mktemp -d)"`; trap EXIT que faz `pkill -f "Wineup Player.app/Contents/MacOS/Wineup" || true` e `rm -rf "$TMP"`.

3. `afconvert -f flac -d flac "$TMP/sine.wav" "$TMP/sine.flac"` e `afconvert -f m4af -d aac "$TMP/sine.wav" "$TMP/sine.m4a"`.
4. Para cada arquivo em sine.flac, sine.m4a, sine.wav: guardar `BEFORE=$(ls ~/Library/Logs/DiagnosticReports/Wineup-*.ips 2>/dev/null | wc -l)`; `open -a "$APP_ABS" "$TMP/<arquivo>"`; `sleep 5`; exigir `pgrep -f "Wineup Player.app/Contents/MacOS/Wineup" >/dev/null` senão erro "app morreu tocando <arquivo>"; exigir contagem de .ips igual a BEFORE senão erro "crash report novo ao tocar <arquivo>"; `pkill -f "Wineup Player.app/Contents/MacOS/Wineup" || true; sleep 1`.
5. Imprimir "Reprodução OK (FLAC, M4A, WAV)".
Em build-app.sh, depois de verify-app.sh: `if [ "${SKIP_SMOKE:-0}" != "1" ]; then ./scripts/smoke-playback.sh "$APP"; fi`.
