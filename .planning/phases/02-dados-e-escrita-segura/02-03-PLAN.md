`LibraryTrack.swift`: `public struct LibraryTrack: Sendable, Equatable, Identifiable { public let id: Int64 /*audio_file.id*/; path: String; title: String; artist: String; album: String; genre: String?; trackNumber: Int?; discNumber: Int?; duration: Double?; status: FileStatus }` + `public var url: URL`. Um único SQL base (JOIN audio_file/release_track/recording/artist/release) reaproveitado pelos dois serviços.

`SearchService.swift`: `public struct SearchService: Sendable { init(database: LibraryDatabase); public func search(_ text: String, limit: Int = 200) async throws -> [LibraryTrack]; static func ftsQuery(_ text: String) -> String? }`. `ftsQuery`: separa por espaços/pontuação, remove `"` e caracteres não alfanuméricos de cada token, descarta tokens vazios, monta `"tok1"* "tok2"*` (cada token entre aspas, palavras-chave como AND/OR/NEAR viram literais por estarem entre aspas); nil se não sobra token. Consulta `... WHERE track_fts MATCH ? AND audio_file.status = 'present' ORDER BY rank LIMIT ?` via `pool.read` (concorrente, fora da main).

`BrowseService.swift`: métodos async via `pool.read` listados no behavior; structs `ArtistSummary {id, name, trackCount}`, `AlbumSummary {id, title, artist, year, kind, trackCount}`, `GenreSummary {name, trackCount}`, `FolderSummary {path, trackCount}`. Adicionar `public static let uncategorizedGenre = "Sem categoria"` (gênero NULL/'' mapeado via `COALESCE(NULLIF(genre,''), ?)` com argumento vinculado) e `public func singles() async throws -> [LibraryTrack]` (álbum virtual "Singles" = consulta: release title 'Unknown Album' ou release com COUNT(release_track presente)=1; `AlbumSummary` virtual com id -1 e título "Singles" exposto por `public func singlesSummary()`). Só status present por padrão (parâmetro `includeMissing: Bool = false`). Pasta: agrupar por diretório pai do `path` (`substr` até a última "/" em SQL ou agregação em Swift sobre a lista da raiz) — documente a escolha.
